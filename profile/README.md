### LibreRTC

**[LibreRTC](https://github.com/svllvsxprod/librertc)** brings together a desktop client, server node and shared RTC tunneling runtime. These are components of one system.

[Overview & documentation](https://github.com/svllvsxprod/librertc) · [Windows client](https://github.com/svllvsxprod/librertc-client) · [Server & admin panel](https://github.com/svllvsxprod/librertc-node) · [Core runtime](https://github.com/svllvsxprod/librertc-core)
